# Music beds

These three loops are **original**, generated by `tools/make_music.py` from
sine/saw voices and synthetic drums. No samples, no attribution, no network.

| File | Mood | Use |
|---|---|---|
| `lofi.wav` | warm, low-key | podcasts / talking heads |
| `pulse.wav` | 120 BPM, electronic | gameplay / GTA |
| `cinematic.wav` | slow pads | general / story |

They are mixed at a low gain and ducked under the voice with a sidechain, so
they set a floor without competing with speech. Regenerate with:

```bash
cd backend && ./venv/bin/python tools/make_music.py
```

## Using real tracks

Drop royalty-free tracks you have the rights to into `gaming/`, `podcast/` or
`general/` (mp3, wav, m4a, aac, ogg, flac). They replace the generated loops
for that genre and rotate across the clips in a job. `general/` is the fallback
for any genre with an empty folder. The bed is still ducked under speech and
faded at both ends automatically.
